# Language-label font

`NotoSansCJK-LanguageLabels.otf` is a glyph subset of
`NotoSansCJKsc-Regular.otf` from the official
[Noto CJK repository](https://github.com/notofonts/noto-cjk). It contains only the characters used
by the Korean, Japanese, Simplified Chinese and Traditional Chinese names in the language picker.
The source file was downloaded from repository `main` on 2026-07-30 and had SHA-256
`2C76254F6FC379FDDFCE0A7E84FB5385BB135D3E399294F6EEB6680D0365B74B`.
